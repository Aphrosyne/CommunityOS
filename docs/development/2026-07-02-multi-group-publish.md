# 发布多群选择

> **日期：** 2026-07-02
> **功能：** 发布前自动判断用户所在群，支持多群选择
> **结果：** ✅ 单群自动选，多群用户自选，支持多选

---

## 设计

`IMAGE_SUBMIT_GROUP`（单群号）→ `IMAGE_SUBMIT_GROUPS`（逗号分隔群号列表）。

发布时调用 `bot.get_group_list()` + `bot.get_group_member_info()` 查询用户归属：
- 0 个启用群 → 拒绝
- 1 个 → 自动选择
- 2+ 个 → 用户回复数字选择（可空格分隔多选）

目标群列表写入 Session（`target_group_ids`），完成后一条消息同时发送到所有选中群。

群查询使用 `asyncio.gather` 并行，启动时 O(启用群数) API 调用。

## 踩坑

### 闭包变量未传参

`_in_group` 通过闭包引用循环变量 `gname`，`asyncio.gather` 调度时变量已变。改为显式传参 `_in_group(gid, gname)`。

### 群选择阶段无法取消

「取消」检测排在群选择逻辑之后，数字选择期间用户无法退出。将「取消」提到最前面，任何阶段均可用。
